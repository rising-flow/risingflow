Images folder organization

This folder contains site images and small galleries used by the Rising Flow site.

Goal: provide structured manifests and a place for optimized assets so the new `js/services/SongService.js` / future `ImageService` can read galleries without scanning directories.

Recommended structure:

- images/
  - _manifests/        # JSON manifests for galleries and groups (used by JS services)
    - carousel.json
    - pixel_block.json
  - _optimized/        # generated optimized assets for production (webp, resized)
  - carousel/          # current carousel images (source/original)
  - PixelBlock/        # pixel block source images
  - logo and backgrounds at root

Notes:
- Keep original source files (high quality) in the gallery folders.
- `_optimized/` should be generated by the build step (not stored in VCS if large) and referenced in manifests.
- Use manifests to list images, alt text, and optional captions.
